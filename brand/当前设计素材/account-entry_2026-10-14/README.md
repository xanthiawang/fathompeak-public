## 认证服务接入后才完成的流程

1. 国内手机号验证：服务端识别已有身份或创建新账户，再建立会话。
2. 国内微信：真实微信授权、取消/过期/失败处理；是否要求绑定手机号按实际服务规则确认。
3. 邮箱：已绑定邮箱验证码登录；验证码发送、有效期、重发限制均以服务端结果为准。
4. 国际 Google / GitHub：正式应用配置、授权回调、身份绑定和取消/失败处理。
5. 登录后的企业、教育认证与账户资料流程，以及真实 API Key / 用量 / 账单接入。
6. 接入时明确地区、语言、身份服务与数据区的关系。本轮 UI 以语言展示不同方式，没有建立两个账户库，也没有假设跨区域互通。
