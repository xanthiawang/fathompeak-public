# 小程序竞品 UI 研究

采集日期：2026-10-14。用户已明确不再要求优先寻找无问芯穹、硅基流动小程序，转向其他相似产品。

## 当前证据

- Kimi：取得2024-04-08公开测评中的小程序首页、语音输入截图。是历史资料，不是当前实拍。
- 元宝：取得2024-09-18公开报告第7、8页的小程序首页和文件总结流程。官方元器文档仍列有元宝小程序入口：https://yuanqi.tencent.com/guide/share-agent 。当前视觉需复核。
- 创客贴作图神器：官网 https://www.chuangkit.com/clientpage 明确列出微信小程序及二维码。只核实入口，未进入内部页面。
- 无问芯穹、硅基流动：保留已采集的官方 Web 首页，作为企业端补充；不标记为小程序。

## 观察与下一步

这批历史图反映两种表达：Kimi以输入和示例任务为主；元宝将任务卡、内容推荐和对话放在一起。二者都把常用输入操作放在屏幕下部。创客贴可作为任务型设计工具的候选，尚不能依据入口页评价其小程序内部设计。

要支持沐仞 ToC / ToB 直接购买并使用的定位，还必须补拍：任务选择、生成结果、额度不足、套餐权益、支付前确认、订单和个人中心。当前没有足够证据评价任一产品的小程序购买闭环，也未验证企业空间与成员权限。
