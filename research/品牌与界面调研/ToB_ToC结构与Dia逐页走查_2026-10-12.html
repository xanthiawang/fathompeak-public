一、Dia 的九个页面，每页长什么样

共用的是胶囊导航、纸底、黑胶囊按钮、衬线与无衬线交替的标题。每页不同的是首屏的"色场"：一幅油画，或一片色雾，或什么都没有。它决定这一页的情绪。

首页 /

黄色油画色场铺满首屏，巨大衬线 "Dia"，产品截图压在上面，一个黑按钮 "Download Dia for free"。导航只剩三项：What's New / Apps / Security。

Apps /apps Zixin 点名

深绿油画风景做成一条横带，向下渐隐进纸白；黑色衬线大标题落在纸上；app 图标散在两侧。往下是 "Featured apps" 四张卡，缩略图用油画局部；再往下是纯白卡片网格。

For Work /forwork

淡彩天空式的模糊色雾（薰衣草、桃色），无衬线标题 "Dia is built for work"，产品截图。下面全是 FAQ 折叠：SOC 2、是否用企业数据训练、AI 安全控制、MDM、SSO、导入。没有"联系销售"。

Security /security

纯纸面文档页：左侧目录，右侧长文，无衬线标题。放在导航里，是给 IT 采购看的。

Release notes /release-notes/latest

纸面，衬线标题，Mac 与版本号做成小标签；功能两栏排，每条末尾 "Shipped by" 加一个手写签名。

Changelog /changelog

深色油画横幅（绿底橘猫），白色衬线 "What's new in Dia"。下面是年 / 月侧栏加筛选胶囊的时间线，页面很长。

Windows /windows

纸面，无衬线标题，一个黑按钮，一张截图（截图里嵌了一幅画）。

Help /help

Dia logo 居中，一句欢迎语，一个支持聊天窗；底部是淡彩色雾。FAQ 不在营销页上，在这里。

Early Birds /earlybirds

夜空渐变（蓝到紫到黑），app 图标，白色按钮；"How it works" 三张深色卡。

二、Dia 怎么分 To B 和 To C

一个产品，一个按钮

个人和企业装的是同一个 Dia，首页只有一个 "Download"。网站上没有登录，账号在应用里。

B 的区别在"信任内容"，不在入口

导航放 Security，页脚放 For Work 和 Trust Center。For Work 页本身就是一组 IT 采购会问的 FAQ，没有联系销售的按钮。

结论：当产品对个人和企业是同一个东西时，不做两个入口，做一页回答企业顾虑的内容。

两三句，放在顾虑出现的页面：首页底部、价格页、企业页。

Dia 的做法：营销页上只有 For Work 放 FAQ，其余问答都在单独的 Help。

八、补证：API 平台怎么放企业页和登录（2026-10-12 晚）

Zixin 问「企业与出海」页参考了谁的逻辑。除了 Dia For Work 和无问芯穹，再抓三家同类 API 平台：

OpenRouter 首页

导航 Models / Benchmarks / Chat / Rankings / Apps / Pricing / Docs，右上角 Sign Up。首屏对开发者说话：Get API Key。页脚单列 Business、Enterprise 两页和 Trust Center。

OpenRouter /enterprise

一句话 + Contact sales + 客户 logo；往下依次是痛点对照、企业级功能（可观测、成本上限、零留存）、合规与计费（信用卡 / 开票 / 信用额度）、企业协议（支持、SLA）、再一次 Contact sales。

硅基流动首页

导航 产品 / 模型 / 价格 / 文档 / 生态合作 / 关于，右上角「登录」。页脚把 B 端拆成单独页面：私有化大模型服务平台 /enterprise、AI 算力运营服务 /token-factory、预留实例。

硅基流动统一登录

独立登录页：手机号 + 短信验证码，「注册 / 登录」一个按钮，微信与邮箱登录备选。个人与企业同一入口。

PPIO 首页

导航末尾三件套：控制台 / 登录 / 立即注册。「控制台」在未登录时指向的就是登录页。页脚有「企业 Token Plan」单独页面。

结论
  • 自助层和销售层分开成两页，是 API 平台的通行做法：OpenRouter、硅基流动、PPIO、无问芯穹都这样做，差别只在 B 页放导航还是页脚。沐仞的 B 线有两条（企业采购、词元出海），所以合成一页「企业与出海」放进导航。
  • 登录是一个独立页面，个人与企业同一入口；控制台只有登录后才出现（PPIO 的「控制台」链接未登录时落到登录页）。原型 v12 照此改。
  • 企业页内容的来源：三种合作方式与采购四步来自公司 BP 与英文销售册；企业 FAQ 的结构来自 Dia For Work，问题来自 BP 的卖点（牌照、来数加工、绿色凭证）加 OpenRouter 企业页也回答的采购通问（计费、SLA、支持、数据留存）；「个人 vs 企业」对比表的行是 B2B 采购通行项，属于假设，已标示例，待公司确认。
