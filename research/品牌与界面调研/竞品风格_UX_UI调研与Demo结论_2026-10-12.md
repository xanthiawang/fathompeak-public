# 竞品风格、UX / UI 调研与色彩 Demo 结论

日期：2026-10-12（第二轮，接 `竞品品牌调研与品牌方向_2026-10-12.md`）
Demo：https://claude.ai/artifact/AcsvsFU7yPHD76TUzSFcgk（私有链接；源文件 `demo/沐仞品牌色彩Demo_2026-10-12.html`）
原始材料：`ux/`（模型市场、定价、文档页，17 个页面）、`ux_home/`（首页动效与技术信号）、`mobile/`（390px iPhone 模拟，10 个页面）。每个文件夹里的 `extracted_styles.json` 记录了导航、CTA、表单、价格、动画数量、脚本库等信号。

## 1. 图形与动效风格

| 品牌 | 图形语言 | 动效 | 技术信号（首页） |
|---|---|---|---|
| 硅基流动 | 浅紫渐变 banner、深色卡片配线框几何纹理 | 轮播、滚动淡入 | 22 组 keyframes，无 3D 库 |
| PPIO | 淡蓝玻璃立方体（3D 渲染图）、浅蓝白底 | 轮播、8 个常驻动画、1 段视频 | 35 组 keyframes |
| 无问芯穹 | 黑底紫光等轴测芯片城市插画 | 11 段视频、203 组 keyframes，页面最"重" | 大量图片（354 张） |
| OpenRouter | 几乎无插画，用模型 logo 墙和延迟折线图当图形 | 无轮播，极少动画 | 18 组 keyframes |
| Together | 彩色抽象 3D 几何（蓝紫橙），等宽小标签 | GSAP + Swiper，9 个常驻动画 | 321 张图片 |
| Crusoe | 机房实拍 + 等轴测线稿（微电网、园区）、荧光黄绿色块 | GSAP，7 段视频，3 个 canvas | 等宽大标题 |
| Emerald AI | 数据中心航拍实景，衬线斜体标题 | GSAP，2 段视频，几乎无 CSS 动画 | 新闻卡片为主 |
| Soluna | 风机航拍、实地照片、规模数字（MW） | Swiper 轮播，1 段视频 | 40 组 keyframes |
| 沐仞现网 | 无插画；蓝绿渐变标题 + 交易看板表格 | 3 组 keyframes | 无图片 |

规律：
1. **国内 AI 平台偏"装饰性 3D"**：玻璃立方体、等轴测芯片、紫光粒子。它们和产品本身没有关系，换一个 logo 就能给另一家用。
2. **海外开发者平台偏"数据即图形"**：OpenRouter 用模型 logo 墙、延迟曲线、规模数字；Together 的定价页就是一张可筛选的大表。
3. **能源公司偏"实景 + 线稿"**：真照片建立信任，等轴测线稿解释系统结构（Crusoe 的微电网线稿是好例子）。
4. 动效上，**轮播几乎是国内标配，但海外开发者平台都不用**。重度动效（无问芯穹）会拖慢加载，对 To C 手机端不利。

**沐仞的风格建议**：
- 图形主语言用**数据**：峰谷曲线、交易看板、绿电账单。这些都是沐仞业务里真实存在的东西，竞品抄不走。
- 辅助语言用**电站实拍 + 等轴测线稿**：实拍建立"后厂"的可信感，线稿解释"调算找电"的系统结构（电站 → 一体机 → 平台 → 用户）。
- 不用 3D 玻璃体、紫光粒子、自动轮播。
- 动效只做三种：看板数字进场、曲线绘制、悬停态。全部遵守 `prefers-reduced-motion`。

## 2. UX 结构对比

### 2.1 导航与首屏动作

| 品牌 | 一级导航 | 首屏主 CTA |
|---|---|---|
| 硅基流动 | 产品 · 模型 · 价格 · 文档 · 生态合作 | 登录 / 立即试用 |
| PPIO | 模型服务 · Agent 云 · GPU 云 · 边缘云 · 新闻 · 关于 | 立即注册 |
| OpenRouter | Models · Benchmarks · Chat · Rankings · Apps · Pricing · Docs | **Get API Key** |
| Together | Inference · Compute · Model Shaping · Research · Developers · Pricing | Start building |
| 智谱 | 研究 · 产品 · 文档 · 体验 · 定价 · 支持 | 登录 / 注册 |
| 沐仞现网 | 主页 · 控制台 · 文档 · 模型市场 · 节点定价 · 节点评价 · 发起任务 · 融合智慧算网中枢 | 立即询价购算 / 浏览模型市场 |

沐仞的问题：导航有 8 项，"节点定价""节点评价""发起任务""融合智慧算网中枢"是供给侧或内部概念，开发者看不懂；首屏 CTA"立即询价购算"是 B 端销售动作，不是自助接入。OpenRouter 的"Get API Key"是最直接的开发者动作，建议采用。

### 2.2 模型市场

| 品牌 | 形态 | 卡片 / 行里有什么 | 筛选 |
|---|---|---|---|
| 硅基流动 | 卡片网格 | 厂商 logo、模型名、发布日期、长描述、能力图标、上下文、参数量 | 类型、应用场景（RAG、Vibe Coding 等 20 个标签） |
| PPIO | Playground 优先（左侧参数、右侧对话） | 当前模型价格、上下文 | 模型下拉 |
| OpenRouter | 列表 / 表格切换 | 名称、Token 用量、描述、输入输出价、分类标签 | 模态、价格、上下文、Series、Zero data retention 等 12 组 |
| Together | 卡片网格 | 名称、缓存 / 输入 / 输出价、部署方式标签 | 类别、提供商 |
| 沐仞现网 | 卡片网格 | 模型名、厂商、一句描述、上下文、**市场价**、"选择此模型获取特价" | 全部 / Chat / Reasoning |

沐仞的卡片结构其实已经接近 Together，缺的是：价格只有"市场价"一个数，没有输入 / 输出分开；"获取特价"把价格藏在询价后面，和竞品"价格公开"的做法相反；筛选只有 3 个。

### 2.3 定价页

- **全行业统一单位**：¥ 或 $ / 百万 Token，输入、输出、缓存命中三列。
- **峰谷分价已经出现**：DeepSeek 官方（空闲 / 高峰，高峰翻倍）、硅基流动（"费用发生时段 9 点～18 点"按时段分价）。这说明"按时段定价"用户已经能理解，沐仞的"高峰平价"有直接的对照基准。
- 智谱把定价做成卡片 + 问答机器人；Together 做成 18 张可筛选的表；Crusoe 把 GPU 和推理分开列。
- 沐仞现网没有公开定价页，"节点定价"是供给侧概念。

### 2.4 文档与接入

硅基流动、PPIO、OpenRouter、Kimi 的文档都是同一套结构（Mintlify 风格）：左侧目录、`⌘K` 搜索、"复制页面"、"提出问题"输入框、llms.txt 索引。OpenRouter 的 Quickstart 第一屏就是一段可复制的 `curl`。沐仞文档页在导航里，但本次未能抓到有效内容，需要单独核查。

### 2.5 手机端（390px）

- 硅基流动、PPIO、OpenRouter、智谱的手机端都正常：卡片单列、汉堡菜单、CTA 保持在首屏。
- OpenRouter 手机端把筛选收进"Filter"按钮，列表仍然可读，是最好的参考。
- **沐仞现网手机端首页为空白**：在 iPhone 模拟下，首页的 iframe 内容没有渲染，页面只剩导航和页脚（`mobile/fp_home_long.png`）。模型市场页正常。需要真机复核，如果属实，这是 To C 之前必须修的第一件事。

## 3. UI 细节对比

| 项 | 竞品做法 | 对沐仞的建议 |
|---|---|---|
| 字体 | 国内：系统中文字体 + Roboto / Inter；海外：自定义字体（The Future、Suisse、Plus Jakarta）+ 等宽字体做数字和标签 | 中文 Noto Sans SC（OFL 授权），数字和价格用 IBM Plex Mono，让看板和账单有"计量"感 |
| 价格排版 | 一律等宽或 tabular-nums，输入 / 输出分列 | 同上；每个价格都带单位"/ M" |
| 卡片 | 1px 边框 + 8px 圆角 + 白底，几乎不用阴影（OpenRouter、Together） | 同样克制；只有悬停加边框色 |
| 主 CTA | 单一实色按钮，页面只有一种主色按钮 | 深色底用能源青，浅色底用深能源青 |
| 状态标签 | 小圆角 chip，等宽小字（Together 的 SERVERLESS / DEDICATED） | "平价窗口 12:00–15:00"做成同类 chip，是沐仞独有的状态 |
| 深色模式 | 沐仞现网外壳已有深色开关；OpenRouter、PPIO 文档有 | 首页深色、市场与文档浅色，与 demo 一致 |

## 4. Demo 评估：两个方案是否成立

Demo 把同一套五块画板（官网首屏、模型市场、峰谷定价与账单、组件、手机首屏）在方案 A、B 之间切换，并实时计算色卡对比度。

**方案 A（深海蓝 + 能源青）**
- 成立。深色首屏上能源青做按钮、曲线和看板数字，辨识度够，与竞品的紫和蓝明显拉开。
- 弱点在"峰"：平价窗口、减排、按钮都是同一个青，首屏看不出哪个最重要。深色底上只能靠亮度区分，空间有限。

**方案 B（加峰光琥珀 #F2A93B）**
- 琥珀只出现在四处：首屏曲线的高峰窗口、标签圆点、市场卡片的"平价"chip、账单里的绿电和减排两行。这样用，峰值一眼可见，故事"从谷到峰"在视觉上成立。
- 弱点：琥珀在白底上对比度只有 2.0，浅色页面必须换成深琥珀 #9A5B00，等于多维护一组色值；用多了会像电商促销标。

**建议**：以 A 为基线，B 作为"峰"的状态色，只允许用在"平价窗口 / 减排 / 绿电"三类信息上，其他地方一律不用琥珀。这样既保留 A 的克制，又让品牌故事里的"峰"有专属颜色。

Demo 里的所有价格和看板数字取自现网 2026-10-12 展示值，24 小时曲线是示意，账单是样式示例。

## 5. 待核查与待决定

1. **手机端首页空白**：真机确认。
2. **看板数据是否真实**：决定它能否做品牌签名元素。
3. **是否公开定价**：竞品全部公开，沐仞现网把价格藏在"获取特价"后面；To C 必须公开。
4. **导航精简**：建议改为 模型市场 · 峰谷价格 · 文档 · 电站网络 · 控制台，供给侧功能移到"电站合作"二级入口。
5. **实拍素材**：电站、一体机、集装箱照片，以及可公开的范围。
6. **字体授权**：Noto Sans SC 为 OFL，可商用；若要用 HarmonyOS Sans 或其他字体需核对条款。
