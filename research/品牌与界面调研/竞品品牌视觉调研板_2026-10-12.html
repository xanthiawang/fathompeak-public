沐仞科技｜竞品官网与品牌视觉调研

采集时间：2026-10-12。工具：无头 Chrome，1440×900 视口。色值取自页面实际计算样式（computed style）与 CSS 变量；色差算法为 CIEDE2000。截图与原始数据见 data/ 文件夹。
  1. 国内模型 API 平台的颜色高度同质：紫色（硅基流动 #6C28F6、无问芯穹 #5D2BFE、OpenRouter #7624F4）或标准科技蓝（PPIO #1161FE、DeepSeek 平台 #3B82F6），配 3D 玻璃或抽象几何插画，首屏都是"新模型上线"轮播。
  2. 能源 + AI 公司走"实景 + 大地色"：Crusoe 荧光黄绿 #CEEB13、Emerald 深绿 #253023、Soluna 锈橙 #CB5727，使用真实机房、电站、风机照片，配衬线或等宽字体，语气偏宣言式。
  3. 沐仞的蓝撞色：现网主蓝 #2563EB 与 PPIO 主色色差 ΔE 2.2；品牌规范 V1 的亮蓝 #176BFA 色差 3.4，接近肉眼难分。
  4. 能源青 #169FB0 是空白色区：与所有竞品主色色差都大于 25；但白底对比度只有 3.17，需要配一个深色版本用于文字和按钮。
  5. "Token 工厂 / 词元"已被占用：PPIO 写"面向 Agent 时代打造 Token 工厂"，无问芯穹导航有"Token工厂"，硅基流动推"TokenPlus 词元优选"。沐仞 BP 里的"词元工厂"不再具有区分度。
  6. 沐仞的独有元素：现网"实时词元交易看板"（电站 × 模型 × 成交价 × 减排量）在所有竞品中都没有出现，可以作为品牌标志性资产，前提是展示的是真实数据。
  7. 自身一致性问题：首页 iframe 的页面标题写"拼好算"；外壳与首页用了两套配色（#3EA4EC 与 #2563EB），都不是规范 V1；联系邮箱是 fathompeak@163.com；BP 上印的 www.fathompeak.tech 证书已于 2026-10-02 过期。
