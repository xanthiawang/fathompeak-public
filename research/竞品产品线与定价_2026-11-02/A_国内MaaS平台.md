## 1. 火山引擎·火山方舟（字节跳动）

**1. 产品线**

- **方舟模型推理**，分五种模式：
  - 在线推理（常规）；
  - 在线推理（低延迟，只有部分豆包模型）；
  - 在线推理（低优）：价格约为常规的 50%；
  - 批量推理；
  - TPM 保障包：文档写着"暂无支持的模型"。
- **自研模型**：
  - 豆包 Seed 2.1 Pro / Lite / Turbo，Seed 2.0 Pro / Lite / Mini；
  - 视频 Seedance 2.5、图像 Seedream 5.0 Pro、音频 Seed-Audio 1.0；
  - 同时上架 DeepSeek V4 系列。
- **个人订阅**：
  - Coding Plan Lite / Pro；
  - Agent Plan Small / Medium：多模态 + Harness，含 Seedance、Seedream。
- **Agent 企业基础设施（2026-06 FORCE 大会发布）**：方舟 CLI、AgentKit、HiAgent 3.0、ArkClaw 企业版 Agent 工作台、AI Trust 产品体系、扣子。

**2. 定价**

- 企业智能体：HiAgent、ArkClaw。
- 手机和汽车厂商的端云合作。

**4. 销路**

- **大客户直销**：年用 Token 超过 1 万亿的企业已有 200+ 家；超过 110 万家企业和个人在用方舟。来源：[新华网](https://www.news.cn/tech/20260623/acd6f2f27fc34459a7d1684c03278431/c.html)，2026-06-23。
- **销售激励**：行业传闻火山卖 Token 的提成是卖云产品的 10–20 倍，2023 年就建了 MaaS 销售体系。来源：[36氪 / 中国企业家](https://www.36kr.com/p/3827233550603143)，2026-05-27【媒】。
- **其他**：控制台自助；FORCE 大会；个人订阅用低价首月拉新。

## 14. 横向规律与对沐仞的含义【判断】

1. **订阅制已经从"Coding Plan"换成了"Token Plan"，并分成个人和企业两层。**
   - 阿里（2026-03 停售 Coding Lite）、百度（2026-06 停止续费）、腾讯都把按请求次数计费的 Coding Plan 换成了按 Token 或积分抵扣的 Token Plan。
   - 个人档：28–600 元/月。
   - 企业档有三种形式：
     - 按席位：阿里 150–1,398 元/席/月；
     - 按月预算：腾讯 5,000–20,000 元/月；
     - 按融合额度：PPIO 1,598–13,998 元/月。
   - 沐仞的"月度预购"产品可以参照这三种形式定档：席位适合团队，月预算适合企业，融合额度适合开发者。

2. **"闲时折扣"已经是标配，单靠时段定价做不出差异。**

   | 平台 | 闲时或低价档 |
   |---|---|
   | DeepSeek 官方 | 非高峰 5 折 |
   | 火山 | 低优档约 5 折 |
   | 阿里 | 22:00–08:00 Qwen3.7 低至 2 折 |
   | 百度 | 21:00–08:00 2 折 |
   | 七牛 | 18:00–08:00 0.3 倍 |
   | 硅基 | 2:00–8:00 半价 |
   | 无问 | 22:00–08:00 半价 |

   - 这些都按"用户需求的低谷"定时段，没有一家按电站出力或电价曲线定时段，也没有一家在账单上写明绿电来源。
   - 沐仞要讲的不是"晚上便宜"，而是三件事：价格时段跟着电站出力走、可追溯的绿电和碳凭证、以及中午光伏大发时段的价格低谷（同行都是夜间低价）。

3. **同一模型各家基本同价，价格锚是 DeepSeek 官方的峰谷价。**
   - DeepSeek V4 Pro 在火山、百度、PPIO 都是 9 / 27；阿里和硅基是 12 / 24。
   - 七牛的"包年 4 折 × 闲时 0.3 倍"等效约 1.2 折，是目前查到的最低条件价。
   - 沐仞"4 折起"如果写成无条件价，单价最低；但别人可以靠叠加条件压到更低。所以沐仞的报价要讲清"无条件价"和"条件价"的区别。

4. **收入集中在大厂。独立平台赚钱靠的不是 Token。**
   - 2026 年上半年 MaaS 市场 106.3 亿元，火山约占 45%【媒】。
   - 独立平台怎么赚钱：
     - 硅基：公有云毛利 −119%，本地部署 82.5%；
     - PPIO：靠边缘云撑着，整体毛利率 9.4%；
     - 并行科技：靠算力合同（智算 6.47 亿元，毛利率 19%）；
     - 优刻得：GPU 时租。
   - IDC 口径下，2026 年上半年大模型私有化部署市场 28.8 亿元，同比 +108%。
   - 沐仞"一体机私有化 + 电站合作"的利润空间，比卖 Token 大得多。

5. **大厂靠高额销售激励和伙伴分成卖 Token。**
   - 阿里：每卖 1 万元 Token，奖励 1:1 业绩；伙伴随 Agent 一起卖，阿里抽 30%，伙伴另得 1.5 倍系数。
   - 火山：传闻 Token 提成是云产品的 10–20 倍【媒】。
   - 独立平台的打法：开发者漏斗（免费模型、代金券、预置进 Dify / Cherry Studio）；集成商；和运营商、国资合作运营（硅基 Token 工厂、并行科技合资建中心）。
   - 沐仞没有大厂的销售规模，更适合走三条路：
     - 电站和能源集团的合作通道（联合运营、私有化）；
     - 渠道伙伴分成：参考阿里的系数思路，伙伴的 Agent 产品里用 Token 越多，奖励系数越高；
     - 出海：Token 出口已有网信办许可，可以上 OpenRouter 这类聚合平台。

6. **直接对手要分层看。**
   - 叙事层面：共绩科技（清华、闲时算力、算电协同、以算代储、宁德时代生态）最近。
   - 商业模式层面：无问芯穹（政企、异构调度、私有化）、硅基 Token 工厂（联合运营分成）、并行科技（国资合资建中心）最近。
   - 价格层面：火山低优档、七牛 Token Plan。
