## 一、几个共同规律

1. **主收入都是"容量"，不是 Token。** 海外原矿企转型后，收入几乎全是按 MW 托管或按 GPU 小时的长约：Core Scientific 约 144 万美元/MW/年【算】，Hut 8 约 190 万美元/MW/年【算】，IREN 和 Nscale 是数十亿美元的多年 GPU 合同。Token 只是 Crusoe 云业务里的一个入口。
2. **"灵活性"单独卖的钱不多，但能换来并网和扩容。** Soluna 2026Q1 需求响应收入 54 万美元，只占总收入约 6%【算】。Emerald 的核心卖点不是需求响应补贴，而是让数据中心"用可核验的灵活性换更快并网"（和 Silicon Valley Power 的灵活负荷并网计划）。国内上海已把数据中心纳入虚拟电厂，下一步是容量激励，金额还没公布。
3. **国内发电企业正在自己往算力走。** 大唐（中卫）、晶科（中卫 1 GW）、甘肃电投（庆阳）、中能建（庆阳）、远景（乌兰察布）都在做"电 + 机柜 / 算力"打包。他们缺的是算力运营、调度和市场化交易能力，这是沐仞"联合运营 / 整套系统私有化"的直接买方。
4. **电网侧在建"算电协同平台"，碳凭证开始按单出具。** 扬州平台按单核算碳排放并出具溯源凭证；上海建了 15 家的生态圈。沐仞的绿色 Token 交易平台可以对接这些平台，而不是另起炉灶。
5. **最直接的国内对手是共绩科技和特锐德。** 共绩做"需求侧"：聚合别人的闲置卡，按秒计费、抢占价打 6 折；特锐德做"设备侧"：卖供电舱 + PowerBrain OS。沐仞的位置在两者之间：电站侧自有一体机 + 调度模型。

## 二、对沐仞产品线和定价的具体建议

| 方向 | 参照 | 沐仞可以怎么做 |
|---|---|---|
| 绿电窗口价 | 共绩 Job 批处理抢占价（约 6 折） | Token 和卡时分三档：实时价、可延迟价（绿电窗口内执行）、可中断价（弃电时段执行）。可延迟、可中断两档的折扣幅度由世界模型按弃电预测定 |
| 电站侧托管 / 联合运营 | Lancium（电力房东）、Soluna（风电场共址）、Core Scientific（按 MW 托管） | 和电站签"出地出电、沐仞出设备和运营"的分成；参照按 kW·月计费，或按算力收入分成 |
| 世界模型软件授权 | Emerald Conductor、特锐德 PowerBrain OS、Phaidra | 给发电企业、园区、数据中心卖调度软件：一次性私有化部署费 + 按纳管 MW 的年费；价格要自己定，对手都没公开 |
| 电网调节收益 | 国网上海 VPP、Soluna ERCOT 需求响应、Google 需求响应协议 | 一体机集群申报虚拟电厂调节能力；收益和电站或客户分成 |
| 碳 / 绿电凭证 | 扬州按单碳溯源凭证 | 每笔 Token 订单出具绿电比例和碳排放凭证，可做付费增值项，服务出海客户 |
| 交付形态 | 联通三江源（一体机 / 私有化 / 云） | 沐仞产品线也按这三种形态排，各自定价 |
| 融资结构 | IREN 客户预付 20%、Hut 8 由 Google 兜底租约 | 大客户长约要求预付或第三方兜底，用于一体机采购融资 |

## 三、分公司详情

### 3.1 共绩科技（ComNergy，北京）

1. **产品线**（[suanli.cn 官网](https://www.suanli.cn/)）：弹性服务部署、Job 批处理、大模型云服务（按量计费、无订阅费）、云主机、裸金属（按 8 卡时 / 24 小时 / 7 天 / 30 天打包）。官网自述用"算电协同"技术和闲时算力调度，没有展开。
2. **收费**（[价格页](http://www.suanli.cn/price/)）：
   - 弹性部署和云主机按秒计费，挂牌卡时价举例：4090（24G）1.98 元、5090 3.25 元、H20-96G 12.00 元、H100 22.50 元、H200 35.00 元、昇腾 910C 13.20 元。
   - Job 批处理分按需价和抢占价，抢占价约为按需价的 6 折：4090 1.98 / 1.19 元，H800 25.00 / 15.00 元，A800 7.80 / 4.68 元。
   - 页面没有专门的"闲时 / 绿电"价格。
3. **经营数字**：
   - 2025 年"数千万营收"，Pre-A 投后估值 3.5 亿元（[快科技转极客公园，2026-04-08](https://news.mydrivers.com/1/1114/1114406.htm)）【未核】；另一转述称"2025 年营收近 3,000 万元并实现盈利，2026 年目标亿级"【未核】。
   - 2026-05 近亿元 Pre-A，春华创投、彼岸时代领投（[36氪，2026-05-07](https://www.36kr.com/p/3799065589406724)）。
   - 论文口径：42 个智算中心、9 省、70 万+ 节点、1.8 万用户（见本地笔记 `算电协同论文_清华共绩_2026-10-25/论文阅读笔记_2026-10-25.md`）。
4. **卖给谁**：AI 应用和模型公司，案例有面壁智能（成本降 68%）、LiblibAI（降 50%）、Tripo（降 40%）、Remy（96 小时内扩到近 2,000 卡）（官网、36氪）。
5. **销路**：自助平台 + 销售；参与京津冀、长三角、深圳、青海省级算力调度平台，在谈国家算力中心合作（快科技）。36氪报道称其在和风光电场、虚拟电厂合作做算力调度和电价联合优化，并计划把夜间闲置算力换成 Token 卖到海外。
6. **对沐仞**：抢占价是"绿电窗口价"的现成样板；他们在电侧只有电价信号，沐仞在电站侧有实测出力和弃电数据，这是差异。他们也在说"夜间算力换 Token 出海"，和沐仞"词元出海"撞题，需要在对外材料里写清区别。

### 3.2 Emerald AI（美国）

1. **产品**：Emerald Conductor。四项功能：实时连接电网和数据中心、编排 AI 负载和现场能源、跨数据中心机群优化、用可审计的计量数据核验表现。灵活性分三类：时间（暂停或放慢可批处理任务）、空间（跨区迁移）、资源（调用电池和现场电源）（[官网](https://www.emeraldai.co/)）。
2. **收费**：官网和公开资料都没有价格。官网说法是把用电变成"可变现资产"、延后昂贵的电网升级。
3. **数字**：
   - 2026-08-25 A 轮 1.5 亿美元，估值 10.5 亿美元，Energize Capital、DCVC 领投，NVIDIA、Samsung、Siemens、GE Vernova、RWE、JERA 等跟投（[Pulse 2.0](https://pulse2.com/emerald-ai-raises-150-million-series-a-at-1-05-billion-valuation-as-platform-targets-100-gw-of-untapped-u-s-grid-capacity/)）。另有报道称申报文件显示 1.5 亿中已售 9,020 万（[Runtime Wire](https://runtimewire.com/article/emerald-ai-90-million-150-million-equity-offering)）【未核】。
   - 演示：Phoenix Oracle 数据中心高峰期 3 小时降负荷 25%（官网称已发表于 *Nature Energy*）；伦敦 National Grid 演示 200 个功率目标 100% 达成；弗吉尼亚到芝加哥毫秒级推理迁移；加州首个整座数据中心多 MW 部署；Manassas 约 96 MW NVIDIA Vera Rubin 参考设计（官网）。
4. **卖给谁**：数据中心开发运营商、电力公司和电网运营商、AI 公司和云厂商、监管方（官网）。
5. **销路**：NVIDIA、Oracle、Digital Realty 等技术伙伴背书；电力伙伴有 National Grid、NextEra、Dominion、PJM、Silicon Valley Power 等；和 Silicon Valley Power 的灵活负荷并网计划用"可核验、可调度的灵活性"换更大的并网额度（Pulse 2.0）。
6. **对沐仞**：最接近"世界模型 + 调度软件"单独售卖的海外样本。它说明灵活性的第一价值是"换并网 / 扩容"，其次才是补贴。沐仞对电站和园区的话术可以照搬：一体机集群是可核验的灵活负荷。
