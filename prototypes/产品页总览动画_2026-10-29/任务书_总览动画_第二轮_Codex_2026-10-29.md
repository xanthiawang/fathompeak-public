# 第二轮：修改本目录的总览动画（ov-anim.css / ov-anim.js / layers/）

我已在真实 Chrome 里截图验收第一轮（见 `验收截图_第一轮_管道四帧.png`、`验收截图_第一轮_整帧.png`），问题：
1. **流动光点几乎看不见**：现在是 5px 粗的短虚线，混在蓝色连接管里分辨不出。改成明显的发光光点：实心圆点（视图坐标半径约 7）+ 外圈柔光（半径约 18、透明度 .35），沿路径移动（SVG `<circle>` + `<animateMotion>` 或 CSS `offset-path`），每根管 1–2 个点、错开出发。下行用 #2F63B8，上行用 #5284D7 外圈配白芯，能一眼区分方向。
2. **层间接缝露白线**：各层错开浮动时，切图边界处出现 1–2px 白缝（管道和连接盒附近最明显）。修法任选其一并说明：给每层切图向下多留 8–12px 出血、由上一层覆盖；或接缝附近用渐隐重叠；或改为相邻层同相位、只让整体浮动幅度不同。要求任何帧都没有白缝。
3. **动感不够**：浮动幅度加大到视图坐标约 8–10px（原图 1254 坐标系），周期 6–8 秒，层间相位错开；再在每层平台的蓝色电路走线上加 2–3 条「沿线跑动」的小光点（半径约 4，沿已有的蓝线走），让平面上也有数据在流。电力层的风机叶片可以缓慢旋转（如果能单独切出叶片且不穿帮；做不干净就不做）。
4. 当前点亮层的高亮可以再清楚一点：边缘描边透明度 .8，光晕 .6。

保持不变：零依赖、`.ov-anim` 作用域、`ovlayer` 事件接口、悬停暂停、`prefers-reduced-motion` 静止、新增图片总量 ≤ 650KB、颜色限定。
