# 任务：把沐仞官网产品页「总览」的四层等轴测插画做成动态图

## 参考
无问芯穹 https://www.infinigence-ai.com/agentic-infra/llm-inference.html 首屏：一张等轴测线稿插画循环播放，数据点沿连线流动、模块轻微浮动，安静、技术感、不花哨。我们要同样的气质。

## 素材
- `engineering-stack_2026-10-14.png`（本目录，1254×1254，透明底）：四层等轴测平台，自上而下：
  1. 接入层（服务器 + 终端）→ 对应产品「绿色 Token 交易平台」
  2. 调度层（芯片）→「算电协同世界模型基座」
  3. 计算层（散热 + GPU 一体机）→「FPTM 系列 Token 一体机」
  4. 电力层（光伏、风机、储能柜）→ 光伏、风电、水电场站
  层与层之间有竖直连接管和小方盒。层中心大约在图高 20% / 42% / 63% / 85%。

## 要做的动画（用代码做，不要视频、不要 GIF）
1. 四层平台缓慢上下浮动、彼此错开（像无问那样的「呼吸」），可以把 PNG 按层切成 4 张透明图（用 Python/PIL 按每层平行四边形区域加遮罩切，连接管归上层或单独一张），切图要干净、拼回去和原图一致。
2. 沿竖直连接管有两种光点流动：蓝色 #2F63B8 自上而下（订单下发），浅紫/青色自下而上（Token 与产地卡回传）。用 SVG path + stroke-dashoffset 或 offset-path 实现，坐标对准原图的连接管位置。
3. 每层轮流点亮一次（约 2 秒一层、8 秒一轮）：该层平台边缘出现一圈淡蓝光晕或描边高亮。点亮时对外发出事件，方便右侧文字同步高亮：`root.dataset.layer = '0'..'3'`，并 `root.dispatchEvent(new CustomEvent('ovlayer',{detail:{layer:i}}))`。鼠标悬停某层时停在该层。
4. `prefers-reduced-motion: reduce` 时全部静止，只显示原图。
5. 不出现任何文字（文字在网页右侧 HTML 里）。

## 技术要求
- 纯 HTML + CSS + 原生 JS，不引外部库；组件根元素 `<div class="ov-anim" data-layer="0">`，所有样式限定在 `.ov-anim` 下。
- 自适应：容器宽度 280–620px 都要正常（用 viewBox / 百分比定位，不写死像素）。
- 新增图片总大小 ≤ 600KB（切图可转 WebP，同时保留 PNG 备用不必要）。
- 颜色只用：#2F63B8、#5284D7、#A9C3E8、#4E3F66、#D6CBDD 及其透明度。

- `ov-anim.css`、`ov-anim.js`：可直接嵌入网站的组件代码
- `README.md`：嵌入方法（HTML 片段、资源路径、事件接口）
