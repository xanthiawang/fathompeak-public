## 沐仞能给的（站内既有事实）
- 按 Token 用量计费，先测试后报价；对公转账、月度结算、增值税发票；主账号 + 子账号、组织钱包共用。
- 算电世界模型按时段、节点调度，可延后的批量任务排进绿电时段，按时段定价；急单走实时通道；主要面向非实时或弱实时推理，SLA 经测试写入协议。
- 模型：GLM、DeepSeek、Qwen、MiniMax 等主流开源/国产模型。
- 来数加工在境内合规处理，签约前可做数据与安全评审。
- 私有化：一体机部署在客户机房或实验室，数据不出域，智能体接入企业工具，沐仞远程运维。
- Token 出海：出海运营主体在汕头，持中央网信办 Token 出海业务批复，合规文件签约前可提供。
- 每单产地卡：电站、时段、用电量、减排量，可用于 ESG 披露与绿色采购。
- 渠道商与平台方：价格与结算按协议。

## 第二轮（10-29 晚，Zixin：痛点/优势/价值要有报道和 paper 依据）

### 痛点 1：Token 用量暴涨，预算失控
- IDC 中国博客《您的公司，准备好 Token 预算了吗？》（2026-03-19）：企业级 Token 年消耗量一年增长近 20 倍；六成以上头部企业已把生成式 AI 放进核心流程，其中三成以上出现「AI 调用成本难以控制」；沿用软件订阅制预算会形成「成本黑洞」；没有单独核算就看不出每笔 Token 带来的业务价值。建议：Token 单独列预算、分层配额、留约 20% 弹性、与业务价值实时对应、跨财务/IT/业务治理。https://www.idc.com/?p=111246
- Ramp（2026-04 付款数据）：月支出中位数约 2,246 美元、均值约 14 万美元，少数团队或无人值守流程拉高均值；换旗舰模型成本可涨 10–100 倍且管理者看不到。https://ramp.com/blog/ai-token-cost-for-businesses

### 痛点 2：自建算力看着便宜，实际利用率低
- Patil, arXiv:2606.11690（2026-06-10）：公开成本计算器默认 GPU 满载，低到中等企业负载（1–10 请求/秒）下实际成本被低估 2.5–24 倍，接近空闲时 36 倍；同一 H100 每百万输出 Token 有效成本 0.21–15.25 美元。https://arxiv.org/abs/2606.11690
- arXiv:2607.13080（企业编码智能体云 vs 本地）：共享 GPU 时本地部署 TCO 约省 40%，独占预留反而比带缓存的 API 贵。https://arxiv.org/abs/2607.13080

### 痛点 3：数据安全与合规是首要顾虑
- Code Ninety 2026 年 1–2 月 142 位技术负责人调查：数据隐私、治理与合规 61.3% 居首，幻觉 54.9%，API/算力成本 31.7%。https://codeninety.com/research/enterprise-ai-adoption-survey-2026
- Gallagher 2026 AI 采用与风险调查：数据保护与隐私违规 55%。https://www.ajg.com/news-and-insights/features/ai-adoption-and-risk-benchmarking-2026/
- 金融、医疗、政务受等保 2.0、《数据安全法》约束，私有化是刚需（行业文章，二手）。

### 痛点 4：AI 碳排放算不清，披露要可辩护
- Bistline et al., arXiv:2608.06733（2026-08-07）：企业 AI 用量排放「目前没有被广泛接受的方法」；已发表的单次查询估算「可相差几个数量级」；利益相关方要求可辩护的数字。https://arxiv.org/abs/2608.06733
- Llopis-Garcia et al., arXiv:2606.10660（2026-06-09，v2 10-15）：企业多把外购 AI 推理漏报，或用按金额的排放因子——比物理估算高 1.7–12.3 倍，且分不出模型和地区。https://arxiv.org/abs/2606.10660
- A 股 2026 年首次强制披露范围一、二排放（交易所指引解读）。

### 痛点 5：出海调用合规链路长，灰色代理多
- 中伦：Token 出海横跨数据出境、技术出口、AI 监管与国际贸易，境内外两套合规叠加。https://www.zhonglun.com/research/articles/56176.html
- 同花顺 2026-07-28：海外大模型 Token 代理靠低价倒卖额度走红，部分站点虚报计费、模型掉包、退款套利，数据传输「几近裸奔」。https://news.10jqka.com.cn/20260728/c678469248.shtml

### 对应的沐仞价值（只用站内事实）
- 预算：按 Token 用量计费、先测后报价、主子账号与组织钱包、逐单用量 → 正好是 IDC 建议的「单独核算、对应业务」。
- 价格：算电调度把批量任务排进绿电时段，公开价 4 折起（10-29 Zixin 定）。
- 不必自建：按量买 Token 不担 GPU 闲置；要私有化也有一体机 + 远程运维。
- 碳：产地卡给每单实测用电量与减排量 → 不用按金额估算。
- 出海：持网信办批复的正规通道，计费与模型逐单可查，区别于灰色代理。
