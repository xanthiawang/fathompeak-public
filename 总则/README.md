## 一、UI 总则（官网与后台）

### 色彩

| 用途 | 值 |
|---|---|
| 页面基底 / 卡片 | `#F8F8F8` / `#FFFFFF` |
| 墨色 | 官网 `#000000`；后台 `#212021` |
| 品牌强调 | 文字晨蓝 `#2F63B8`；填充晨蓝 `#5284D7` |
| 深色搭配 | 暮紫 `#3D314F`、炭黑 `#212021`；功能紫 `#4E3F66` |
| 浅色辅助 | `#DCE7F7`、`#EEF3FB`、`#EAE4F0`；雾色 `#A9C3E8`、`#E3ECF8`、`#EBCFC4`、`#D6CBDD` |
| 后台表头 | 105° 渐变：晨蓝 0% → 暮紫 66% → 炭黑 100%，文字白 94% |
| 边线 | 暮紫 14%（`--line`）、暮紫 8%（`--line-2`）、暮紫 22%（`--frame`），卡框 1px |

- 透明填充和文字分开设色，不对整个组件降低透明度。
- 合作方 logo 保持原色。
- 当前是浅色主题；后台只在表头用局部深色，不是全站深色模式。

### 字体与字号

| 用途 | 字体 |
|---|---|
| 标题 | Fraunces；中文 Noto Serif SC |
| 正文、界面 | DM Sans；中文 Noto Sans SC |
| 数字、代码、标签 | DM Mono |
| 花体首字母 | Pinyon Script 子集，只修饰英文标题的首字母；中文标题不用 |

| 位置 | 规格 |
|---|---|
| 首页主标题 | clamp(28px, 3.2vw, 40px)，字重 400，字距 −.025em |
| 后台一级标题 | 40px / 1.12（≤760px 时 30px） |
| 后台区块标题 | 28px / 1.2（≤760px 时 24px） |
| 后台正文 | 15px / 1.55；说明文字墨色 70% |
| 后台表头 | 11px 等宽，字距 .08em |

字号按页面和断点变化，不用一套全站固定梯度。

### 组件与表面

- 筛选条：白 86%，模糊 12px，细阴影。
- 提示卡：白 60%（悬停 78%），圆角 16px，细线加轻阴影。
- 图标：功能图标紫 `#4E3F66`；导航当前项与悬停用晨蓝 `#2F63B8`；图标容器 36×36、圆角 12px、暮紫 7.5% 底。

### 动态与插画

- 后台排线插画：黑白排线主体叠深色色片，边缘透明融进卡片，不另加实色方框。
- API Key 页树影背景：模糊 7px，10 秒往复；只在可见、未暂停、且系统没有开「减少动态效果」时播放；有暂停按钮。

### 文案

- 中英文分别核对；按钮用明确的动词。
- 界面里不写「示例」「演示」「待确认」这类模板文字，不把演示数据当成真实结果。

## 二、视觉总则（品牌与物料）

### Logo（v31，层叠峰面 + 中英字标）

- 字标是定制轮廓，**没有可安装的字体**。不要用 Noto Serif、宋体、普通无衬线字或衬线 FathomPeak 重新打字代替；直接用 `wordmark-en.svg` / `wordmark-zh.svg`，或 primary / circle / square 完整组合。
- 中文全称写「沐仞科技」，不缩写成「沐仞」。
- 等比缩放，禁止拉伸；中英文视觉居中、基线一致；小尺寸用 SVG。
- 图形和黑白灰渐变不变；晨蓝、暮紫用于界面与版面强调。
- 主标、圆形、方形、独立中英字标、微信头像都必须用同一版（v31）。
- 正文、说明、UI 标签仍用正文字体，不用字标。

文件位置：[brand/logo/层叠峰面_中英字标统一_v31_2026-10-20](../brand/logo/层叠峰面_中英字标统一_v31_2026-10-20/)。

### 色彩与质感

- 用晨蓝、暮紫、雾色和炭黑这一套色卡，配色按[色彩过渡研究](色彩过渡研究_2026-10-13.html)走渐变过渡，不做硬拼的色块。
- 透明表面和细边线参考 Dia；排线拼贴插画参考 Every。这些只作为参考方向，配色仍用沐仞自己的色卡。
